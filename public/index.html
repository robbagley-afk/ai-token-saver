Install by pasting a prompt

Copy one prompt and paste it into the AI app you want it installed in. An app with a terminal, such as Claude Code or Codex, installs it and checks it. A chat app without a terminal answers with the exact clicks.

Use in ChatGPT

  1. Open Plugins. If AI Token Saver has been shared with you, install it there.
  2. For direct access, choose Add custom MCP server, enter AI Token Saver, paste the server URL below, choose No authentication, and create the plugin. Your workspace may require admin approval. This adds the live tools; the full package also supplies the guidance workflow.
  3. In a new supported chat, select AI Token Saver and ask: Recommend a model and effort for this task. Cite the current Revision.
Use in Codex
Download the plugin package and add it through your client's supported plugin interface. Repo marketplace instructions are in the README. Client and workspace support can vary.
Use more than one platform?
The All Platforms edition gives the same live guidance for Claude, ChatGPT, Codex, Gemini and Grok, builds one setup prompt that adds the guidance to your instructions and one refresh task on each platform you choose. In Claude Code run /plugin marketplace add robbagley-afk/ai-token-saver and then /plugin install ai-token-saver-all@ai-token-saver. In Codex add the same repository as a marketplace and install AI Token Saver (All Platforms). In any other client that supports MCP, add the server URL above with no authentication and ask for guidance by platform name. Install one edition per client.
Optional setup
Ask the plugin to set up your instructions. It asks which platforms you use and gives you one prompt, with the app to paste it into. That app sets up every platform it can reach on your computer. For the rest, each app writes the handoff prompt for the next. Each platform gets one instruction block and one task, AI Token Saver guidance refresh, that runs every two weeks on Saturday at 10 PM and refreshes the block when the guide changes. Existing guidance-refresh tasks are found first and only one stays active. Tasks that publish a guide are never touched. Nothing is edited without your yes.
What this does
Recommends settings and cites the source Revision. You select the model yourself. Savings depend on the task. Benchmark API prices are not subscription usage estimates. The plugin does not automatically run on every prompt.
