Guidance updates when you use the plugin. No local server or browser automation needed. Optional instruction setup and a weekly refresh check are offered on first use.

Use in ChatGPT

  1. Open Plugins. If AI Token Saver has been shared with you, install it there.
  2. For direct access, choose Add custom MCP server, enter AI Token Saver, paste the server URL below, choose No authentication, and create the plugin. Your workspace may require admin approval. This adds the live tools; the full package also supplies the guidance workflow.
  3. In a new supported chat, select AI Token Saver and ask: Recommend a model and effort for this task. Cite the current Revision.
Use in Codex
Download the plugin package and add it through your client's supported plugin interface. Repo marketplace instructions are in the README. Client and workspace support can vary.
Use more than one platform?
The All Platforms edition gives the same live guidance for Claude, ChatGPT, Codex, Gemini and Grok, sets up one instruction block on each platform you choose, and offers one weekly change check for all of them. In Claude Code run /plugin marketplace add robbagley-afk/ai-token-saver and then /plugin install ai-token-saver-all@ai-token-saver. In Codex add the same repository as a marketplace and install AI Token Saver (All Platforms). In any other client that supports MCP, add the server URL above with no authentication and ask for guidance by platform name. Install one edition per client.
Optional one-time instructions
Ask the plugin for its bootstrap instruction block. The first-use offer covers ChatGPT/Work account Custom Instructions and Codex instructions separately. Paste the stable block into each surface you choose. This is optional: explicitly selecting the plugin already works. Recommendations continue fetching live guidance without replacing your instructions. You can also opt into one weekly task that checks Revision and reports changes. The host must support and verify scheduling. Existing matching tasks are reused. The task never edits settings or publishes the source guide.
What this does
Recommends settings and cites the source Revision. You select the model yourself. Savings depend on the task. Benchmark API prices are not subscription usage estimates. The plugin does not automatically run on every prompt.
