If guidance cannot be fetched, try again later. The plugin refuses to present expired cached guidance as current. If a recommended model is missing from your account, tell the assistant which models are available. You still choose the setting yourself.

If plugin installation is disabled, ask your workspace administrator. A custom MCP connection supplies tools, while the complete plugin package supplies both tools and the repeatable workflow.

Report reproducible issues at GitHub Issues. Include the public Revision and client type, but omit prompts, private records, credentials and account details.
